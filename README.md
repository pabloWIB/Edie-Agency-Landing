# Edie - Web Agency Landing Page

## Descripción

Sitio web estático para Edie, una agencia web especializada en crear servicios web hermosos y rápidos. La página incluye showcase de servicios, portafolio de trabajos y presentación del equipo.

## Características del Sitio

### Navegación Principal
- **Home**: Página principal con hero section
- **Services**: Servicios ofrecidos (UI/UX, Frontend, Backend)
- **Our Works**: Portafolio de proyectos realizados
- **Clients**: Testimonios y clientes
- **Contacts**: Información de contacto

### Servicios Ofrecidos
- **UI/UX Design**: Diseño de interfaces y experiencia de usuario
- **Front End**: Desarrollo frontend con tecnologías modernas
- **Back End**: Desarrollo backend y arquitectura de sistemas

### Propuesta de Valor
- "Unhappy with your website?"
- "We create beautiful and fast web services"
- "Story, emotion and purpose"
- "Good design means good business"

## Uso

Esta es una página estática que muestra los servicios y portafolio de la agencia web Edie. Incluye:

1. **Presentación de servicios** con call-to-actions
2. **Galería de proyectos** para mostrar experiencia
3. **Testimonios de clientes** para generar confianza
4. **Información del equipo** para humanizar la marca
5. **Formulario de contacto** para captar leads
